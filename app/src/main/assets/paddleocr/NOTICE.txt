PaddleOCR captcha recognition assets
====================================

captcha_rec.onnx
  PP-OCRv5 text recognition model, exported to ONNX.
  Project: https://github.com/PaddlePaddle/PaddleOCR
  ONNX export reference: https://github.com/monkt/paddleocr-onnx
  License: Apache License 2.0
  Copyright (c) PaddlePaddle Authors

captcha_dict.txt
  Character dictionary used by the recognition model.
  License: Apache License 2.0
  Copyright (c) PaddlePaddle Authors

The assets are bundled locally so captcha images never leave the device.
Inference is performed with ONNX Runtime (MIT License):
https://github.com/microsoft/onnxruntime
